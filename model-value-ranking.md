# Model value ranking

Last substantive update: **2026-09-26**
Metric version: **v1 — input-price value**

This artifact ranks broadly frontier-competitive language models by:

\[
\text{Value} = \frac{\text{Artificial Analysis Intelligence Index}}{\text{uncached input price in USD per 1M tokens}}
\]

The inclusion floor is an Artificial Analysis Intelligence Index v4.3.2 score of **21**. It was recalibrated from 28 when AA replaced Terminal-Bench v2.1 with the materially harder v4.0 and replaced τ³-Banking with AutomationBench-AA. The v4.3.2 methodology revision did not materially change the scale, so the floor remains 21; Qwen3.6 27B is now the lowest qualifying member at 21.4, while GPT-5.4 Nano fell to 20.7 and is no longer included. For models with multiple reasoning settings, the score is the best currently scored configuration exposed in the live data, unless that setting lacks comparable public access or pricing; in that case, the strongest generally available scored configuration is used and identified. Prices are standard, non-batch OpenRouter input prices; free endpoints are excluded rather than treated as infinite value. Open and proprietary models are included. Calculations use AA's unrounded scores; displayed scores are rounded to one decimal.

## Interpretation

This metric answers a narrow question: **how much benchmark score is purchased per dollar of uncached input?** It deliberately ignores output and reasoning-token prices, token consumption, retries, latency, cache economics, and task success rate. Models that are terse or cheap on input but expensive or verbose on output can look better here than they do in a real agent workload.

Useful operational slices:

- Raw ratio leaders: DeepSeek V4 Flash 0731, Ling 3.0 Flash, and DeepSeek V4.1 Flash.
- Best 40+ score value: GLM-5.3-Flash on its non-promotional $0.04/M route.
- Best 50+ score value: Claude Opus 5.5 at 57.6 for $4/M input.
- Highest-quality open-weight model: MiMo-V2.6-Pro, followed by GLM-5.3 and Qwen3.8 Max (0902).

The earlier ranking based on the actual full Artificial Analysis evaluation bill remains a better proxy for total agent economics. This input-only version is retained because it is simple, reproducible, and was explicitly requested.
